# Syamu しりとり

Syamuさんのあだ名を使ったしりとりの構成案・整理データの備忘録です。

## 概要
2ちゃんねる（2ch.sc）の特定スレッドから取得したSyamuさんのあだ名データをDeepseekで整理し、Deepseekの思考（Reasoning）モードを活用することで、各種あだ名を使ったしりとりができるように整理・構築したものです。

## データ取得元
* [【悲報】Syamuさんのあだ名、もうめちゃくちゃ - 2ch.sc](https://tomcat.2ch.sc/test/read.cgi/livejupiter/1547159373)

## 処理の流れ・仕組み
1. **データ収集**: 指定スレッドからSyamuさんに関するあだ名一覧を抽出
2. **データ整理**: Deepseekを用いて、重複や不適切なテキストを整理・データベース化
3. **しりとり展開**: Deepseek（思考モード）に整理データを読み込ませ、あだ名同士の文脈や読みを解釈させてしりとりを実行

## 備忘録メモ
* あだ名の読み（平仮名・片仮名）の表記揺れをDeepseek側で補正させることでスムーズなしりとりが可能。
* あくまで個人の備忘録・アイデアメモです。
